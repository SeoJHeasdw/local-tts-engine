# Local TTS Engine

Apple Silicon에서 한국어 강의용 개인 음성을 로컬로 생성하는 독립 프로젝트입니다.
첫 사용처는 `udemy-agent` 강의지만, 이후 다른 강의와 영상에서도 재사용할 수
있는 엔진으로 유지합니다.

## 로컬 제작 앱

터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령 하나로 실행합니다.

```bash
./app.sh
```

앱의 기본값은 사용자가 선택한 Qwen3-TTS 파인튜닝 A(LoRA 강도 0.6)입니다.
30초 미리보기 또는 시작·끝 페이지 묶음을 고르면 음성 생성, 자막, 화면 촬영,
산출물 검증을 한 번에 실행합니다. 페이지 묶음은 시작 페이지의 첫 스텝부터
끝 페이지의 마지막 스텝까지 모두 포함합니다. 완성 파일은 앱의 독립된
`최근 결과` 화면에서 열거나 Finder에 표시할 수 있습니다. 모든 처리와 파일
접근은 로컬에서만 이루어집니다.

`영상 편집` 화면에서는 여러 영상을 드래그로 정렬해 합치거나, 타임코드 또는
연결된 슬라이드 페이지 범위로 구간을 자르고, 영상 화면은 유지한 채 음성 트랙만 교체할 수 있습니다. 교체
음성은 로컬 파일을 고르거나 강의 페이지 범위의 파인튜닝 A 음성을 앱에서
다시 생성할 수 있습니다. 편집 결과도 원본을 덮어쓰지 않고 별도 파일로
저장한 뒤 자동 검증합니다.

왼쪽 아래 로컬 엔진 카드를 누르면 Qwen3-TTS 1.7B와 Chatterbox V3를
전환하고, Qwen 음성 어댑터와 연속 적용 강도(0.10~1.00)를 설정할 수 있습니다.
같은 설정창에서 검수 완료 데이터로 새 LoRA 파인튜닝을 실행할 수도 있습니다.
목소리 교체는 영상 하나를 Finder에서 끌어다 놓고 2~8개의 서로 다른 발화
후보를 만들 수 있습니다. M4 Max 36GB에서는 후보를 최대 두 개씩 병렬 생성한
뒤 팝업의 오디오 플레이어에서 모두 비교합니다. 마음에 드는 후보를 선택해야
그 음성으로 영상 트랙을 교체합니다. 진행과 완료 결과도 팝업으로 표시됩니다.

## 현재 상태

- 프로젝트 뼈대와 영구 작업 지침 구성 완료
- 기존 강의 대본·발음 사전·53분 20초 정제 음성 세트 경로 연결 완료
- 모델 설치와 가중치 다운로드는 아직 하지 않음
- 첫 후보는 Qwen3-TTS 1.7B Base, 비교 후보는 Chatterbox Multilingual V3
- ElevenLabs 결제는 보류하고 로컬 A/B 파일럿부터 진행

## 새 작업에서 시작하기

1. 이 폴더를 Codex의 로컬 프로젝트로 엽니다.
2. 저장소를 신뢰하고 프로젝트 권한 설정을 허용합니다.
3. `AGENTS.md`와 `docs/HANDOFF.md`를 읽습니다.
4. `python3.13 scripts/check_context.py`로 기존 자료 연결을 확인합니다.
5. `docs/BENCHMARK-PLAN.md` 순서로 CH01 30~60초 A/B 샘플을 만듭니다.

## 경계

- 이 저장소: 모델 실행, 개인 음성 프로필, 벤치마크, 로컬 TTS API/CLI
- `udemy-agent`: 강의 대본, 자막, 슬라이드, 영상 렌더와 최종 결과물
- 모델 가중치, 원본 녹음, 생성 음성, 비밀값은 Git에 넣지 않습니다.

자세한 현재 상황은 `docs/HANDOFF.md`, 연결 방식은
`docs/ARCHITECTURE.md`를 기준으로 합니다.

파인튜닝 전 데이터 준비·ASR 초벌 전사·사람 검수·공식 JSONL 내보내기는
`docs/FINETUNING-DATA.md`를 따릅니다. 실제 학습은 이 절차와 분리되어 있습니다.
