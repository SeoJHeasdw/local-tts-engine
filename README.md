# Local TTS Engine

Apple Silicon에서 한국어 강의용 개인 음성을 로컬로 생성하는 독립 프로젝트입니다.
첫 사용처는 `udemy-agent` 강의지만, 이후 다른 강의와 영상에서도 재사용할 수
있는 엔진으로 유지합니다.

## 로컬 제작 앱

터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령 하나로 실행합니다.

```bash
./app.sh
```

앱의 제작 기본값은 `jaeho-ko-r16-v1` LoRA 강도 0.60을 적용한 Qwen3-TTS입니다.
레슨 전체, 페이지 직접 선택, 챕터 전체 중 하나를 고르면 음성 생성, 자막, 화면
촬영, 산출물 검증을 한 번에 실행합니다. 챕터 전체는 한 편의 영상으로 만들거나
레슨 단위로 나눠 각각 촬영할 수 있습니다. 페이지 직접 선택은 시작 페이지의 첫
스텝부터 끝 페이지의 마지막 스텝까지 모두 포함합니다. 완성 파일은 앱의 독립된
`최근 결과` 화면에서 열거나 Finder에 표시할 수 있습니다. 모든 처리와 파일
접근은 로컬에서만 이루어집니다.

`영상 편집` 화면에서는 여러 영상을 드래그로 정렬해 합치거나, 타임코드 또는
연결된 슬라이드 페이지 범위로 구간을 자르고, 영상 화면은 유지한 채 음성 트랙만 교체할 수 있습니다. 교체
음성은 로컬 파일을 고르거나 강의 페이지 범위의 제작 기본 음성을 앱에서
다시 생성할 수 있습니다. 편집 결과도 원본을 덮어쓰지 않고 별도 파일로
저장한 뒤 자동 검증합니다.

페이지 타임라인이 있는 강의 영상에서 페이지 범위를 골라 새 목소리를 만들면
영상 전체 음성을 덮지 않습니다. 선택한 페이지 구간만 교체하고 새 음성 길이에
맞춰 그 구간의 화면과 이후 타임라인만 조정합니다.

왼쪽 아래 로컬 엔진 카드를 누르면 Qwen3-TTS 1.7B와 Chatterbox V3를
전환하고, Qwen 음성 어댑터와 연속 적용 강도(0.10~1.00)를 설정할 수 있습니다.
같은 설정창에서 검수 완료 데이터로 새 LoRA 파인튜닝을 실행할 수도 있습니다.
목소리 교체는 영상 하나를 Finder에서 끌어다 놓고 2~8개의 서로 다른 발화
후보를 만들 수 있습니다. M4 Max 36GB에서는 후보를 최대 두 개씩 병렬 생성한
뒤 팝업의 오디오 플레이어에서 모두 비교합니다. 마음에 드는 후보를 선택해야
그 음성으로 영상 트랙을 교체합니다. 진행과 완료 결과도 팝업으로 표시됩니다.

`목소리 만들기` 화면에서는 강의 페이지나 영상 없이 텍스트만 입력해 2~8개의
서로 다른 발화 후보를 만들 수 있습니다. 후보는 설정된 병렬 수(기본 2개)만큼
동시에 생성되고, 팝업에서 모두 들어본 뒤 하나를 선택하면 `selected.wav`로
별도 보관됩니다. 후보 생성은 이전 오디오 결과를 재사용하지 않습니다.

모델 설정의 `저장 위치`에서는 강의 소스, 내 목소리 원본, 결과물 폴더 세 곳만
선택합니다. 참조 음성과 전사문은 `고급 입력 설정`에 접혀 있습니다. 결과물 폴더의
기본값은 이 프로젝트의 `output/`이며, 앱이 내부를 자동으로 정리합니다.

- 완성 영상: `output/videos/`
- 선택한 목소리와 후보: `output/voices/`
- 강의 TTS 작업 결과: `output/tts/`
- 자막·타임라인 등 제작 파일: `output/projects/`
- 편집 결과: `output/edits/`

경로 설정은 Git에서 제외되는 `artifacts/app-settings.json`에 저장됩니다. 기존
`artifacts/` 아래 결과는 옮기거나 삭제하지 않으며 `최근 결과`에서 계속 조회할 수
있습니다.

제작을 시작하면 화면·대본·자료·장표 순서를 함께 고정하고 정합성을 검사합니다.
그 뒤 원본 강의를 수정해도 이번 제작의 입력은 유지됩니다. 챕터를 레슨별로 만들 때도
같은 판본을 사용합니다. 촬영 전 실제 타임라인 검사 결과는 `lesson-review.json`,
소스 식별값은 `validation-report.json`에 남습니다.

앱에서 강의 영상을 만들 때는 TTS 클립 캐시, 강제 정렬 캐시, 브라우저 HTTP
캐시를 모두 우회합니다. 같은 이름으로 다시 실행해도 음성과 화면을 새로 만듭니다.

강의 음성은 생성 전에 자막 원문과 별도의 발음문으로 정규화합니다. 현재 제작
규칙에는 `Runtime → 런타임`, `Context → 컨텍스트`, `RAG → 래그`,
`IBM → 아이비엠`, `Meta → 메타`, `Qwen3.6-27B → 큐웬삼점육 이십칠비`,
`50개 → 오십 개`가 포함됩니다. 사전과 정규화를 거치고도 숫자로 남은 표현은
한자어 수로 읽어 넘깁니다. 숫자를 그대로 넘기면 모델이 읽는 방식을 스스로
고르기 때문입니다.

만든 음성은 모두 독립된 Whisper large-v3-turbo가 다시 받아씁니다. 비교는 철자가
아니라 발음으로 합니다. 받아쓰기와 대본을 자모로 분해하고 전사에 남은 로마자를
한국어 자모음 이름으로 읽으므로, Whisper가 `이십칠 비`를 `27B`로 적어도 같은
소리로 인정합니다. 청크가 깨끗하게 읽히면 거기서 끝내고, 어긋날 때만 다른 시드로
다시 만듭니다.

발음이 맞아도 단어 안에서 어색하게 멈춘 후보는 추가로 검사합니다. 0.25초 이상의
실제 무음이 단어 내부에 있는지 받아쓰기·단어 시각·실제 발화 구간을 함께 확인하고,
끊김으로 판단되면 같은 제작 목소리로 다시 생성해 후보를 고릅니다. 문장 사이의 쉼과 받아쓰기의 띄어쓰기 차이만으로는
재생성하지 않습니다. 한도 안에 해결되지 않은 구간은 단어 이름과 시간으로 표시됩니다.

판정은 세 단계입니다. 명백한 오독·누락·무음·클리핑은 **재생성 필요**,
애매하게 들린 용어는 **확인 권장**입니다. 확인 권장은 제작을 막지 않습니다.
제작은 끝내고 완료 패널과 최근 결과에 `2:14–2:21 · 148페이지 · 사유` 형태로
구간을 띄우며, 그 구간을 누르면 해당 페이지만 다시 만드는 화면이 채워진 채
열립니다.

새 영상 화면은 `레슨`, `페이지 직접 선택`, `챕터 전체`를 제작 범위로 제공합니다.
레슨 하나를 고르거나, 페이지 범위를 직접 입력하거나, 챕터 전체를 한 편 또는 레슨
단위로 나눠 만들 수 있습니다. 결과 이름, 자막 방식과 음성 전용 출력은 접힌
`세부 설정`에서 바꿀 수 있습니다.
오른쪽에는 선택한 범위·목소리·결과만 요약하고 캐시나 내부 경로는 기본 화면에
노출하지 않습니다.

레슨 목록의 정본은 강의 소스의 레슨 파일
(`deck/src/production/chapters/<ch>/NN-LNN-*.ts`) 하나입니다. **파일 하나가 영상
한 편**이고, 제목은 그 파일 머리 주석에서 읽으며 파일명의 번호가 곧 레슨
순서입니다. 그래서 CH01·CH02처럼 레슨 파일로 쪼갠 챕터는 이 앱이 손댈 것 없이
목록에 올라오고, 아직 한 파일로 남아 있는 챕터만 `deck/narration.config.json`의
preset이 담당합니다.

챕터 여는·닫는 화면처럼 단독으로 영상 한 편이 못 되는 조각은 강의 소스 쪽에서
이미 앞뒤 레슨 파일 안에 들어가 있으므로 이 앱은 다시 묶지 않습니다. 레슨 번호가
없는 파일이나 한 챕터에서 겹치는 L 번호를 만나면 목록이 조용히 어긋나지 않고
오류로 멈춥니다.

레슨으로 만든 최종 MP4는 내부 작업명이 아니라 레슨 제목을 그대로 사용합니다.
같은 레슨을 다시 만들면 기존 파일을 덮어쓰거나 지우지 않고 `(2)`, `(3)`을 붙여
보관합니다. 화면 촬영은 headless Chromium으로 진행하며, 캡처용 강의 서버도
기본 브라우저를 자동으로 열지 않습니다.

목소리 만들기는 텍스트 입력과 생성 버튼을 중심으로 구성합니다. 글자 수, 줄바꿈과
영문 용어 여부만 짧게 표시하며 결과 이름과 후보 수는 `세부 설정`에 둡니다.

`최근 결과`는 강의·목소리·편집 결과를 검색하고 종류별로 거릅니다. 자동 확인과
사용자의 `확인 완료` 상태는 분리되어 각 결과의 `validation-report.json`에 저장되며
언제든 취소할 수 있습니다.

모델 설정은 현재 값이 승인된 제작 프로필
`Qwen3-TTS + jaeho-ko-r16-v1 + 0.60`인지 표시합니다. 실험값으로 바꾸면 경고를
보여 주며 `제작값 복원`으로 승인값을 즉시 되돌릴 수 있습니다. 복원 후에는
`설정 저장`을 눌러 적용합니다.

## 현재 상태

- Qwen3-TTS 1.7B Base와 로컬 제작 앱 연동 완료
- 53분 20초 정제 음성 세트와 원본을 `data/private/voice/`로 이관 완료
- 자막·타임라인과 완성 영상의 기본 출력 위치를 이 프로젝트로 이관 완료
- 텍스트 기반 다중 목소리 후보 생성과 직접 선택 기능 구현 완료
- 챕터 탐색, 결과 검색·필터, 사람 청취 승인과 제작 음성 안전장치 구현 완료
- ElevenLabs는 사용하지 않음

## 환경 진단과 검증

다른 Mac이나 새 셸에서 실행하기 전에는 개인 경로를 기본 출력하지 않는 진단을
먼저 실행합니다.

```bash
npm run doctor
```

텍스트 목소리, 기존 영상 편집, 강의 영상 자동 제작의 준비 상태를 각각 보여
줍니다. 실제 실행 파일과 입력 경로까지 확인해야 할 때만
`npm run doctor -- --verbose`를 사용합니다.

Electron과 Python 테스트를 한 번에 실행하려면:

```bash
npm test
```

제품화 범위, 판매 전 차단 항목과 유료 베타 순서는
`docs/PRODUCTIZATION.md`에 정리되어 있습니다.

## 새 작업에서 시작하기

1. 이 폴더를 Codex의 로컬 프로젝트로 엽니다.
2. 저장소를 신뢰하고 프로젝트 권한 설정을 허용합니다.
3. `AGENTS.md`와 `docs/HANDOFF.md`를 읽습니다.
4. `python3.13 scripts/check_context.py`로 기존 자료 연결을 확인합니다.
5. `npm run doctor`로 앱 기능별 준비 상태를 확인합니다.

모델 설치·A/B 비교·LoRA 선택은 완료된 과거 작업입니다. 사용자가 다시 요청하지
않으면 재실행하지 않고, 현재 제작 프로필을 유지합니다.

## 경계

- 이 저장소: 모델 실행, 개인 음성 원본, TTS 작업, 자막·타임라인, 완성 영상
- `udemy-agent`: 강의 대본, 슬라이드 UI와 캡처 실행 코드
- 모델 가중치, 원본 녹음, 생성 음성, 비밀값은 Git에 넣지 않습니다.

자세한 현재 상황은 `docs/HANDOFF.md`, 연결 방식은
`docs/ARCHITECTURE.md`를 기준으로 합니다.

파인튜닝 전 데이터 준비·ASR 초벌 전사·사람 검수·공식 JSONL 내보내기는
`docs/FINETUNING-DATA.md`를 따릅니다. 실제 학습은 이 절차와 분리되어 있습니다.
