# Local TTS Engine

Apple Silicon에서 한국어 강의용 개인 음성을 로컬로 생성하는 독립 프로젝트입니다.
첫 사용처는 `udemy-agent` 강의지만, 이후 다른 강의와 영상에서도 재사용할 수
있는 엔진으로 유지합니다.

## 로컬 제작 앱

터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령 하나로 실행합니다.

```bash
./app.sh
```

앱의 제작 기본값은 `jaeho-ko-r16-v1` LoRA 강도 0.60을 적용한 Qwen3-TTS입니다.
30초 미리보기 또는 시작·끝 페이지 묶음을 고르면 음성 생성, 자막, 화면 촬영,
산출물 검증을 한 번에 실행합니다. 페이지 묶음은 시작 페이지의 첫 스텝부터
끝 페이지의 마지막 스텝까지 모두 포함합니다. 완성 파일은 앱의 독립된
`최근 결과` 화면에서 열거나 Finder에 표시할 수 있습니다. 모든 처리와 파일
접근은 로컬에서만 이루어집니다.

`영상 편집` 화면에서는 여러 영상을 드래그로 정렬해 합치거나, 타임코드 또는
연결된 슬라이드 페이지 범위로 구간을 자르고, 영상 화면은 유지한 채 음성 트랙만 교체할 수 있습니다. 교체
음성은 로컬 파일을 고르거나 강의 페이지 범위의 제작 기본 음성을 앱에서
다시 생성할 수 있습니다. 편집 결과도 원본을 덮어쓰지 않고 별도 파일로
저장한 뒤 자동 검증합니다.

왼쪽 아래 로컬 엔진 카드를 누르면 Qwen3-TTS 1.7B와 Chatterbox V3를
전환하고, Qwen 음성 어댑터와 연속 적용 강도(0.10~1.00)를 설정할 수 있습니다.
같은 설정창에서 검수 완료 데이터로 새 LoRA 파인튜닝을 실행할 수도 있습니다.
목소리 교체는 영상 하나를 Finder에서 끌어다 놓고 2~8개의 서로 다른 발화
후보를 만들 수 있습니다. M4 Max 36GB에서는 후보를 최대 두 개씩 병렬 생성한
뒤 팝업의 오디오 플레이어에서 모두 비교합니다. 마음에 드는 후보를 선택해야
그 음성으로 영상 트랙을 교체합니다. 진행과 완료 결과도 팝업으로 표시됩니다.

`목소리 만들기` 화면에서는 강의 페이지나 영상 없이 텍스트만 입력해 2~8개의
서로 다른 발화 후보를 만들 수 있습니다. 후보는 설정된 병렬 수(기본 2개)만큼
동시에 생성되고, 팝업에서 모두 들어본 뒤 하나를 선택하면 `selected.wav`로
별도 보관됩니다. 후보 생성은 이전 오디오 결과를 재사용하지 않습니다.

모델 설정의 `저장 위치`에서는 강의 소스, 내 목소리 원본, 결과물 폴더 세 곳만
선택합니다. 참조 음성과 전사문은 `고급 입력 설정`에 접혀 있습니다. 결과물 폴더의
기본값은 이 프로젝트의 `output/`이며, 앱이 내부를 자동으로 정리합니다.

- 완성 영상: `output/videos/`
- 선택한 목소리와 후보: `output/voices/`
- 강의 TTS 작업 결과: `output/tts/`
- 자막·타임라인 등 제작 파일: `output/projects/`
- 편집 결과: `output/edits/`

경로 설정은 Git에서 제외되는 `artifacts/app-settings.json`에 저장됩니다. 기존
`artifacts/` 아래 결과는 옮기거나 삭제하지 않으며 `최근 결과`에서 계속 조회할 수
있습니다.

앱에서 강의 영상을 만들 때는 TTS 클립 캐시, 강제 정렬 캐시, 브라우저 HTTP
캐시를 모두 우회합니다. 같은 이름으로 다시 실행해도 음성과 화면을 새로 만듭니다.

새 영상 화면의 오른쪽 `제작 브리프`는 현재 범위·목소리·산출물·저장 위치와
자동 검증 계획을 시작 전에 요약합니다. 목소리 만들기의 `발화 설계`는 입력한
줄바꿈을 호흡 단위로 보존하고, 글자·호흡·후보·병렬 수와 영문 용어를 실시간으로
보여 줍니다.

717페이지 강의는 새 영상 화면의 챕터 빠른 이동으로 탐색합니다. 이전·다음
페이지로 한 장씩 이동하거나 `챕터 전체`로 해당 범위를 한 번에 선택할 수 있고,
현재 선택한 페이지·스텝 수를 실행 전에 확인할 수 있습니다.

`최근 결과`는 강의·목소리·편집 결과를 검색하고 종류별로 거릅니다. 자동 검증은
파일과 타임라인의 기술적 무결성을 뜻하며, 실제 청취 판단은 별도의 `청취 승인`으로
기록됩니다. 승인 상태는 각 결과의 `validation-report.json`에 로컬로 저장되며
언제든 취소할 수 있습니다. 화면 전환은 `⌘1`~`⌘4`, 현재 작업 실행은 `⌘Enter`,
모델 설정은 `⌘,` 단축키를 사용할 수 있습니다.

모델 설정은 현재 값이 승인된 제작 프로필
`Qwen3-TTS + jaeho-ko-r16-v1 + 0.60`인지 표시합니다. 실험값으로 바꾸면 경고를
보여 주며 `제작값 복원`으로 승인값을 즉시 되돌릴 수 있습니다. 복원 후에는
`설정 저장`을 눌러 적용합니다.

## 현재 상태

- Qwen3-TTS 1.7B Base와 로컬 제작 앱 연동 완료
- 53분 20초 정제 음성 세트와 원본을 `data/private/voice/`로 이관 완료
- 자막·타임라인과 완성 영상의 기본 출력 위치를 이 프로젝트로 이관 완료
- 텍스트 기반 다중 목소리 후보 생성과 직접 선택 기능 구현 완료
- 챕터 탐색, 결과 검색·필터, 사람 청취 승인과 제작 음성 안전장치 구현 완료
- ElevenLabs는 사용하지 않음

## 새 작업에서 시작하기

1. 이 폴더를 Codex의 로컬 프로젝트로 엽니다.
2. 저장소를 신뢰하고 프로젝트 권한 설정을 허용합니다.
3. `AGENTS.md`와 `docs/HANDOFF.md`를 읽습니다.
4. `python3.13 scripts/check_context.py`로 기존 자료 연결을 확인합니다.
5. `docs/BENCHMARK-PLAN.md` 순서로 CH01 30~60초 A/B 샘플을 만듭니다.

## 경계

- 이 저장소: 모델 실행, 개인 음성 원본, TTS 작업, 자막·타임라인, 완성 영상
- `udemy-agent`: 강의 대본, 슬라이드 UI와 캡처 실행 코드
- 모델 가중치, 원본 녹음, 생성 음성, 비밀값은 Git에 넣지 않습니다.

자세한 현재 상황은 `docs/HANDOFF.md`, 연결 방식은
`docs/ARCHITECTURE.md`를 기준으로 합니다.

파인튜닝 전 데이터 준비·ASR 초벌 전사·사람 검수·공식 JSONL 내보내기는
`docs/FINETUNING-DATA.md`를 따릅니다. 실제 학습은 이 절차와 분리되어 있습니다.
