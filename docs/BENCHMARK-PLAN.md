# 로컬 음성 A/B 벤치마크

## 목적

Qwen3-TTS 1.7B Base와 Chatterbox Multilingual V3 중 사용자의 한국어 강의에
실제로 적합한 모델을 짧은 샘플로 고른다. 모델 이름이나 데모 평판으로 승자를
미리 정하지 않는다.

## 고정 조건

- 동일한 10~20초 참조 음성
- 참조 음성의 정확한 한국어 전사
- 동일한 CH01 30~60초 대본
- 동일한 발음 사전 적용문
- 최종 비교 파일은 48kHz mono WAV로 통일
- 후처리는 비교에 필요한 최소 음량 정렬만 적용

## 참조 음성 선정

정제 마스터 다섯 파일에서 후보 2~3개를 찾는다.

- 배경 잡음과 반사가 적음
- 마이크 거리와 음량이 안정적임
- 숨, 입소리, 긴 무음이 과도하지 않음
- 한 문장 안에 평서문과 자연스러운 억양 변화가 있음
- 영어 약어가 없는 기본 후보 하나와, 필요하면 약어가 있는 후보 하나
- 대본과 실제 발화가 정확히 일치함

참조 후보 자체에 노이즈 제거, EQ, 컴프레서, 음색 변형을 먼저 걸지 않는다.

## 대본 선정

`udemy-agent/deck/script/course/ch01.md`의 `ch01-intro` 범위에서 설명문,
인용, 영어 약어가 섞인 30~60초를 고른다. 너무 쉬운 문장만 골라 모델의
오독 문제를 숨기지 않는다.

## 기록할 항목

| 항목 | 판정 |
| --- | --- |
| 사용자 목소리 유사도 | 1~5 + 짧은 메모 |
| 한국어 자모·받침 발음 | 오독 위치 기록 |
| LLM·RAG·MCP 등 약어 | 발음 사전 적용 전후 기록 |
| 강의체 억양 | 과장, 단조, 문장 끝 반복 |
| 안정성 | 누락, 반복, 환각, 비정상 무음 |
| 청취 피로 | 1분과 이후 10분 후보를 분리 판단 |
| 생성 성능 | 모델 로딩, 생성 시간, 최대 메모리 |
| 수정 편의 | 한 클립 재생성의 성공 여부 |

## 통과 조건

- 뜻이 바뀌는 오독과 단어 누락이 없음
- 눈에 띄는 반복, 환각, 비정상 무음이 없음
- 발음 사전으로 주요 약어를 안정적으로 통제할 수 있음
- 사용자가 자신의 강의 목소리로 받아들일 수 있음
- M4 Max 36GB에서 메모리 부족 없이 반복 실행 가능

둘 다 통과하면 음질뿐 아니라 생성 속도, 캐시 재사용, 장문 안정성이 좋은 쪽을
고른다. 둘 다 실패하면 참조 구간과 chunking을 한 번 개선해 재시험하고, 이후에만
미세조정 또는 한 달짜리 클라우드 대안을 검토한다.
