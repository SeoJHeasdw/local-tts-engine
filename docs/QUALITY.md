# 음성 검수 계약과 측정 근거

영상 화질·촬영·편집 검수는 [VIDEO-QUALITY](VIDEO-QUALITY.md)를 따른다.

## 제작 기본값

한국어는 Qwen3-TTS 1.7B Base BF16 + `jaeho-ko-r16-v1` 0.60과 짧은 참조 음성·
정확한 전사를 사용한다. 0.60은 과한 학습 흔적과 사람 발화 노이즈를 줄인 사용자
승인값이다. 모델·음성 제작 기본값은 직접 들은 승인을 받아 변경한다.
제작 도중 미등록 용어의 발음 승인을 요구하지 않는다. 합성을 마친 뒤 기존 검수·
확인 완료·페이지 재생성 화면에서 읽기를 확인한다(2026-09-11 사용자 결정).

영어 인용문은 English·LoRA 미적용·화자 특징 참조(`english-speaker-only-v1`)다.
참조 전사를 생략한다. 영어 생성 iterator가 끝날 때까지 어댑터 기여를 0으로 두고
finally에서 원래 값을 복원한다. 두 번째 대형 생성 모델을 올리지 않는다.

사전의 `literal: true, inline: true`는 승인한 영어 철자를 한국어 문장 안에서
보호한다. 단어·조사를 별도 영어 클립으로 나누지 않는다. 일반 영어 인용문은
문장 전체를 보호해 내부 사전 치환을 막은 뒤 따로 생성한다. 언어 경계에는 120ms를
두고 실제 한국어 RMS를 기준으로 영어에 일정한 게인만 적용한다. 각 언어의 실제
샘플 범위·길이·게인은 `voiceRouting`에 남긴다. 한국어만 있는 캐시 키는 유지한다.

문장 안 영어 철자 방식은 Observation, Anthropic, permission denied(별칭 포함),
Artificial Analysis, Intelligence Index, Boris Cherny, Y Combinator, RICE에 채택됐다.
RICE는 제품 이름만 잡도록 `caseSensitive`를 켠 유일한 항목이다.

사전의 `to`는 **모델이 실제로 읽는 철자**다. inline 항목은 영어 음성으로 보내지 않고
(`speech_segments`가 건너뛴다) 한국어 모델이 그 철자를 직접 읽으므로, 어떻게 읽히는지는
경험으로만 안다. `RICE`는 대문자 약어라 철자로 읽혔다(2026-09-20 3회 모두 불일치:
"알라이 씨", "RIC", "Rih"). 같은 문장에서 `Rice`·`rice`는 3회 모두 `라이스`였다. 그래서
자막 원문은 `RICE`로 두고 발음문만 `Rice`로 보낸다. 대문자 약어를 새로 넣을 때는
`scripts/probe_term_pronunciation.py`로 재고 넣는다.
Authentication/Authorization은 보류, Attention Budget/knowledge cutoff는 불채택으로
기존 한글 읽기를 유지한다. 단어별 영어 전환은 거절됐다. [청취 근거](DECISIONS.md)를 따른다.

## 생성 전 검사

각 레슨의 대본을 읽고 발음문을 만들 때 미등록 용어·식별자를 기록한다.
이 경고는 제작을 막지 않고 완성 후 검수 목록에 연결한다. 대본 누락·잘못된 범위 등
실제 입력 오류는 기존 입력 준비·대본 처리 단계에서 중단한다.

자막 원문과 발음문을 분리한다. 덱·로컬 사전의 같은 키는 로컬 항목이 우선하며
긴 항목부터 적용한다. 영숫자 하이픈 식별자의 일부만 치환하지 않는다.
보호된 영어 문장 안의 숫자·용어는 한글 읽기를 추가하지 않는다.

`korean_naturalness`는 명확한 1~99개·명·가지를 고유어 관형형으로 바꾼다.
사용자 승인 예외 `50개 → 오십 개`를 유지한다. 번·장·시간은 문맥 없이 결정하지
않는다. 사전 이후 남은 숫자는 한자어로 정규화하고, 남은 영문·식별자는 생성 전
기록한다. 미지정 복합 식별자를 임의의 숫자 읽기로 바꾸지 않는다.
명시적으로 등록한 읽기는 제작 사전을 따른다. 다른 식별자를 개별 하드코딩하거나
자동 등록하지 않는다. 미등록 정보는 실제 청크 시각과 연결해 `voiceFindings`에
남기며, 자동 판독이 통과해도 청취 확인 대상으로 표시한다.

## 생성과 독립 판독

청크마다 생성 → Whisper large-v3-turbo 판독 → 깨끗하면 종료, 아니면 다음 시드로
최대 4회 시도한다. 후보 N개를 직접 비교하는 페이지 재생성은 후보당 1회 정책이다.
시드를 바꿔도 같게 읽히는 자리는 사용자가 읽을 말을 직접 적어 후보를 만든다. 이는
그 페이지의 발음문을 사람이 정하는 것이며 자막 원문·대본과 사전은 바꾸지 않는다.
대조할 원문이 없으므로 자동 판독을 돌리지 않고 청취 선택으로만 채택한다.
파일 생성 실패와 음성 경고는 별개이며, 남은 경고는 사람이 확인할 수 있게 표시한다.

Whisper의 긴 음성 판독은 내부 무음 경계로 나눠 30초 창의 뒤쪽 누락을 피한다.
영어·한국어는 생성 시 기록한 실제 구간별로 각 언어를 판독한다. 영어 단어
누락·치환도 재시도 근거다. 원어민 억양·강세·음색은 이 검사의 보증 범위가 아니다.

비교는 `korean_phonetics`의 자모 공간에서 수행한다. 로마자 잔여 표기, 숫자와
모델명을 정규화하고 된소리·ㅐ/ㅔ는 접되 거센소리와 연음은 임의로 접지 않는다.
1차 판독에서 의심된 청크는 다른 디코딩 온도로 한 번 더 읽어 관대한 판정을 취한다.

선언한 `comparisonReading`이 있는 영어 용어는 거리만으로 통과시키지 않고 선언
표기와 정확히 맞아야 한다. 허용할 ASR 표기는 사용자 청취 후 `comparisonVariants`에
넣는다. 반복 용어는 허용 표기들을 합쳐 세며 들린 표기는 `heardReading`에 남긴다.
선언 없는 한국어 음차의 기존 거리 관문은 유지한다.

## 누락과 운율

`transcript_coverage`는 순서를 보존하며 한국어 3단어·10음절 이상의 순수 삭제를
기록한다. 같은 구절이 두 후보에서 반복 누락되면 남은 후보부터 기존 문장부호
경계로 나누어 합성·조립·전체 검수한다. 영어 인용문 내부는 분할하지 않는다.
현재 발음문이 과거 기록과 정확히 일치할 때만 페이지 후보의 누락 복구를 재사용한다.
복구 정책·조각은 캐시 해시에 포함하며 원문·청크 키와 최대 후보 수는 유지한다.

발음을 통과한 후보의 250ms 이상 내부 무음은 Whisper 단어 시각과 Qwen 독립
정렬로 확인한다. 단어 양끝 100ms, 문장·명시적 대기 경계는 보호한다. 정렬이 앞뒤
발화를 놓친 경우에는 인접 단어와 떨어진 미배정 구간의 주기성 발화도 근거로 쓴다.
띄어쓰기·잡음·낮은 확신도·잘못된 시각만으로 재생성하지 않는다.

`restarts`는 60~220ms의 약한 시작음, 70~240ms 쉼, 뒤 발화의 유사도와 두 배 이상
음량을 함께 보고 원문의 같은 단어 안인지 독립 정렬로 확인한다. 원문 반복이나
비슷한 첫 두 음절은 제외한다. 모든 말더듬을 검출하거나 파형을 자동 절단하지 않는다.

발음 정확도를 먼저, 그다음 운율 경고 수와 길이를 비교한다. 운율 경고만으로
오독 실패로 승격하지 않는다. 확인되지 않은 정렬은 근거 부족 상태로 기록한다.
한국어 발화 속도 관문은 한국어 구간에서만 적용하며 영어 속도는 참고 기록이다.

## 검수 관문을 유지하는 근거

2026-09-04 측정과 사용자 판단의 근거다.

| 비교 | 기존 거리 | 해석 |
| --- | --- | --- |
| 엔팔엔 / 엠팔엔 | 약 0.09~0.11 | 자연스러운 약화로 허용 |
| 뱉을 / 배틀 | 약 0.17 | 연음·ASR 표기 차이로 확인 가능 |
| 런타임 / 런팀 | 0.250 | 음절 소실, 재시도 대상 |
| 런타임 / 런트민 | 0.375 | 다른 읽기, 재생성 대상 |

`PRONUNCIATION_MATCH_DISTANCE=0.15`를 자모 하나 차이를 잡기 위해 조이지 않는다.
초성 ㅇ을 제거해 연음을 접으면 런팀의 거리가 0.250에서 0.143으로 내려가
놓치게 된다. CH01 163청크의 오탐 몇 건을 줄이려고 이 탐지력을 잃지 않는다.
여러 낱말인 지정 발음은 구성 낱말의 어휘 검사를 꺼서는 안 된다. 이 중복 제외
수정은 당시 163청크 재판정에서 새 경고 0건이었다.

2026-09-10 Anthropic 첫 모음 오독은 별도의 명시적 사용자 판단이다. 안쓰로픽과
엔트로픽이 모두 거리 0.100이라 전역 문턱으로 구분할 수 없다. 따라서 전역 관문은
유지하고 사전의 선언 표기로 검사한다. 과거 3,090건 재판정에서 Anthropic 23건만
새 경고가 됐다(안쓰로픽 9, 엔트로픽 14). 상세는 [결정 기록](DECISIONS.md)에 있다.
