# 현재 상태와 인수인계

> 갱신: 2026-09-10. 이 문서는 현재 상태만 유지한다. 과거 UI 변경과 완료된
> 실행 절차를 누적하지 않는다. 승인·측정 근거는 DECISIONS와 QUALITY가 담당한다.

## 작업 시작

1. `AGENTS.md`, 이 문서, `ARCHITECTURE.md`, `QUALITY.md`를 읽는다.
2. `python3.13 scripts/check_context.py`로 강의 연결과 음성 정본을 확인한다.
3. `npm run check`로 환경·구조·동작을 검사한다.
4. 현재 작업 트리의 변경을 확인하고, 다른 작업과 사용자의 수정은 보존한다.

Python은 3.13.12다. 기본 검사 환경은 `.venv`, LoRA를 쓰는 제작은
`.venv-train`이다. 새 모델 설치·A/B·학습을 초기 작업으로 반복하지 않는다.

## 승인된 제작 상태

한국어는 Qwen3-TTS 1.7B Base BF16 + `jaeho-ko-r16-v1` 강도 0.60과 짧은 참조
음성·정확한 전사를 사용한다. 0.60은 2026-09-08 비교 후에도 유지하기로 했다.

영어 인용문은 2026-09-09 비교 **5번**, LoRA 미적용·화자 특징 참조·English다.
참조 전사를 주지 않는다. 미국식 발음은 청취 목표이며 자동 검사가 보증하지 않는다.

Observation, Anthropic, permission denied(붙임·밑줄 별칭), Artificial Analysis,
Intelligence Index, Boris Cherny, Y Combinator는 전체 한국어 문장 안에서 영어
철자를 유지하는 0.60 방식으로 승인됐다. Authentication/Authorization은 보류,
Attention Budget/knowledge cutoff는 새 방식 불채택으로 기존 한글 읽기를 유지한다.
단어별 영어 분리 합성은 네 샘플 모두 거절됐으므로 재개하지 않는다.
새 용어는 각각 먼저 들려준다. 세부 승인과 날짜는 [결정 기록](DECISIONS.md)에 있다.

## 최근 구조 정리

- Electron 진입점에서 제작, 편집, 결과 저장, IPC, 창 수명 관리를 분리했다.
  서비스 의존성은 `electron-app/main/application.mjs`에서 연결한다.
- 검수·클립 편집·결과 목록은 `renderer/controllers/`로 분리했다.
- 공통 옵션·타임라인·검수·시간 계산을 `shared/`로, 앱 검사를 `tests/electron/`으로 모았다.
- Python 대본 입력·청킹, 오디오 처리, 정렬을 `course/`로 분리했다.
  `course_pilot` CLI와 기존 helper import는 저장된 검수 명령을 위해 유지한다.
- 완료된 벤치마크 계획과 중복된 제품화 제안서를 제거했다. 과거 UI 변경일지와
  더 이상 현재 작업이 아닌 실행 지시는 삭제했다. 라이선스·음성 선택 근거는 보존했다.
- 새 파일의 위치와 의존성 규칙은 [ARCHITECTURE](ARCHITECTURE.md)를 따른다.

## 최근 기능 수정

실제 짧은 FFmpeg 영상으로 다음을 재현하고 고쳤다.

- 규격이 맞는 영상을 합칠 때 불필요하게 전부 재인코딩하던 문제.
- 음성 트랙 없는 영상의 자르기 시작점이 무시되던 문제.
- 페이지 음성 교체가 다른 페이지의 검수·확인 표시와 자막 파일을 잃던 문제.
- 구조 분리 중 발견한 앱 종료 함수와 과거 편집 탭 초기화의 끊어진 호출.

새 구조에서도 해당 회귀 검사를 유지한다. 모델·발음 사전·제작 기본값 변경과
새 TTS 합성은 이 정리 작업에 포함하지 않는다. 실행 중인 앱에는 재시작 후 반영된다.

## 구조 정리 검증

2026-09-10 최종 `npm run check`: 앱 185개·Python 298개 모두 통과.
앱 38개 모듈의 경로·계층·순환 검사, 문서 링크, Node/Python 구문과 미정의 이름
검사도 통과했다. 실제 강의 목록 784페이지·66레슨을 생성 모듈/MLX 로드 없이 읽었다.
편집은 실제 FFmpeg, 화면은 컨트롤러·전체 초기화, 앱은 전체 IPC 등록·종료를 검증했다.
실제 Electron 창은 이 세션에서 SIGABRT로 종료돼 시각 검증하지 못했다.
실행 중인 사용자 앱을 재시작하거나 새 강의 음성을 생성하지 않았다.

## 유지해야 할 한계와 후속 판단

- 자동 검수는 영어 억양·강세·음색을 승인하지 않는다.
- 영어 단어 내부 끊김·짧은 재시작·영어가 섞인 구절 누락·영어 속도 관문은
  한국어와 검사 범위가 같지 않다. 근거 없이 새 임계값을 추가하지 않는다.
- Anthropic 받아쓰기 `안쓰로픽`과 `엔트로픽`은 선언 표기와 다르므로 확인 대상이다.
  다른 표기를 미리 허용하지 않고, 사용자가 들은 뒤 `comparisonVariants`를 정한다.
- 최신 편집을 다시 고칠 때 원본 manifest 음성으로 돌아가지 않는다. 최신 PCM·
  타임라인·자막과 준비 기록의 해시를 사용한다.
- 실제 MLX 배열 접근 가능 여부는 실행 환경에 따라 달랐다. 테스트 통과나
  `metal.is_available()`만으로 새 합성·청취 성공을 주장하지 않는다.
