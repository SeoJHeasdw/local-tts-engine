## 앱

사이드바는 새로 만들기 · 다듬기 · 영상 편집 · 최근 결과다. 새로 만들기의 탭에서 강의 영상 ·
텍스트 목소리 · 화면 녹화 · 앱 데모를 고르고, 작업은 앱 전체에서 한 번에 하나만 돈다.

- 화면 녹화는 무음으로만 쓴다(음성 포함은 쓰지 않기로 했다). 내레이션은 다듬기에서 넣는다.
- 앱 데모는 새로 만들기에서 찍고, 대본 → 목소리 후보 → 완성본 → 검수는 다듬기의 앱 데모
  작업면에서 한다. 자막은 파일이 기본이고 굽기는 선택이다. RICE는 `RICE_DEMO=1` 데모 모드로 찍고
  시나리오는 `bob/rice/demo/scenarios/`에 있다.
- 앱 코드 변경은 앱을 다시 띄워야 반영된다(`./app.sh`).

## 제작 상태

- 한국어는 Qwen3-TTS + `jaeho-ko-r16-v1` LoRA 0.60, 영어 인용문은
  `english-speaker-only-v1`이다. 강도 설정은 0.01 단위다.
- 미등록 용어도 제작하고 완성 후 검수한다. `B-3102 → 비 삼일공이`,
  `R-042 → 알 공사이`는 사전에 등록돼 있다(CH03의 335·359·389페이지).
- 레슨 분할 제작은 개별 실패 후 나머지를 계속한다. 실패한 레슨의 이어하기를 위해
  고정 입력과 진행 기록을 보존하며, 새 제작의 캐시 금지는 유지한다.
- 다듬기에서 재생성으로 풀리지 않는 읽기는 읽을 말을 직접 적어 후보를 만든다.
  자막·대본은 그대로 두고 발음문만 바꾸며, 자동 판독 대신 사람이 듣고 고른다.
